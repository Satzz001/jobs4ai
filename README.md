# Jobs4AI landing page

A one-page React + Tailwind CSS landing page for Jobs4AI, an early-stage open-source AI job recommendation platform.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

This is a Vite static site and can be deployed to Vercel, Netlify, or GitHub Pages. Use `npm run build` as the build command and `dist` as the output directory. The intended custom domain is `jobs4ai.me`.
